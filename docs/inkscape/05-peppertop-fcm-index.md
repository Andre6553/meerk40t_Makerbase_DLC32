## When to use this index

- Local docs cover official tutorials in `inkscape-master/Learn`.
- Use Peppertop for: **LPEs**, **filters**, **clones/tiling**, **1.x version changes**, **web/SVG/JS**, **JessyInk**, **Shape Builder**, **Selectors/CSS dialog**, **1.4 Filter Gallery**.
